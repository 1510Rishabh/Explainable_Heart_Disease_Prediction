# ❤️ Explainable AI for Heart Disease Prediction

## 📌 Overview

This project predicts the likelihood of heart disease using multiple machine learning models and provides explainable insights for predictions.

---

## 🚀 Features

* Predicts heart disease risk based on medical inputs
* Uses multiple ML models (Logistic Regression, Decision Tree, Random Forest, KNN, SVM)
* Provides model comparison
* Modular project structure for scalability
* Easy-to-use interface via `app.py`

---

## 🧠 Technologies Used

* Python
* Scikit-learn
* Pandas
* NumPy

---

## 📂 Project Structure

```
data/               # Dataset files  
model/              # Training scripts  
saved_models/       # Trained ML models  
utils/              # Helper functions  
heart_disease_app/  # App-related logic  
app.py              # Main application file  
requirements.txt    # Dependencies  
```

---

## ⚙️ Installation

1. Clone the repository:

```
git clone https://github.com/1510Rishabh/House_Price_Prediction.git
```

2. Navigate to project folder:

```
cd your-folder-name
```

3. Install dependencies:

```
pip install -r requirements.txt
```

---

## ▶️ How to Run

```
python app.py
```
